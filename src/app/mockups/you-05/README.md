# Design Doc: Clean Directory

## Goal

Create a search-first landing page that makes GigForge feel usable immediately. The landing page should resemble the actual directory product, emphasizing filters, musician cards, and anonymous browsing.

## Visual Direction

- Style: clean directory/search interface.
- Mood: efficient, crisp, product-forward.
- Background: white.
- Primary text: dark charcoal.
- Accent: teal.
- UI treatment: light gray borders, white cards, subtle gray panels.
- Typography: clean sans-serif with strong but controlled headline.

## Page Structure

1. Overall layout:
   - Two-column desktop layout.
   - Left: positioning copy and CTAs.
   - Right: functional directory preview.
   - Mobile: stack copy then preview.

2. Kicker:
   - Uppercase teal text:
     - `Search-first landing`

3. Headline:
   - Large and direct:
     - `Start with who you need.`

4. Supporting copy:
   - Explain that GigForge turns the landing page into the product by letting visitors filter student musicians and open gigs before signing in.

5. CTAs:
   - Primary dark button:
     - `Explore directory`
   - Secondary outlined button:
     - `View gigs`

6. Directory preview panel:
   - Light gray background panel with border.
   - Search input-style row:
     - `search`
     - `Search instruments, genres, or project types`
   - Filter chips:
     - `+ Instrument`
     - `+ Genre`
     - `+ Remote`
     - `+ Deadline`

7. Musician cards:
   - Two-column grid inside preview.
   - Cards with light border and white background.
   - Titles:
     - Film composer
     - Jazz vocalist
     - Session drummer
     - Cellist
     - Beat producer
     - Piano accompanist
   - Each card has support line:
     - `Portfolio links / Availability / Contact email`
   - Use a small teal marker on each card.

## Implementation Notes

- Make the right-side preview look like a real product surface.
- Avoid marketing flourishes; prioritize utility.
- This concept should be the most straightforward to integrate into the actual app.
