# Design Doc: Tape Deck

## Goal

Create a music-forward landing page for GigForge using an analog tape-deck motif. It should feel musical and memorable without obscuring the marketplace workflow.

## Visual Direction

- Style: analog audio equipment, tape labels, warm music artifact.
- Mood: tactile, nostalgic, creative, direct.
- Background: dark brown/charcoal.
- Primary text: warm cream.
- Accent: saturated golden yellow.
- Secondary text: muted tan.
- UI treatment: chunky bordered cassette/card shape with rounded corners.
- Typography: bold sans-serif plus small mono labels.

## Page Structure

1. Main layout:
   - Two-column desktop layout.
   - Left: hero copy and CTAs.
   - Right: cassette-inspired product card.
   - Mobile: stack.

2. Kicker:
   - Monospace uppercase yellow text:
     - `press play on the project`

3. Headline:
   - Large, bold:
     - `Match the brief to the sound.`

4. Supporting copy:
   - Explain this as an analog-inspired direction that feels musical while preserving marketplace clarity.

5. CTAs:
   - Primary yellow filled:
     - `Play Post gig`
   - Secondary outlined:
     - `Rewind Browse`

6. Tape deck card:
   - Outer card with cream border and dark fill.
   - Inner black/dark inset.
   - Cream label area with yellow border.
   - Label text:
     - `GIGFORGE MIX 01`
     - `Student musicians for real creative briefs`

7. Tag row:
   - Rounded outline pills:
     - score
     - session
     - voice
     - strings
     - beats
     - live set

## Implementation Notes

- Keep the cassette/tape metaphor as a product preview, not a full illustration-heavy page.
- Use warm contrast carefully so text remains legible.
- Avoid too many browns; keep cream and yellow strong enough to lift the palette.
