# Design Doc: Studio Ledger

## Goal

Create a calm, operational landing page for GigForge. This version should feel trustworthy and efficient, like a serious tool for students working against project deadlines.

## Visual Direction

- Style: ledger/table-inspired SaaS utility.
- Mood: focused, mature, quiet, credible.
- Background: cool light gray.
- Primary text: dark blue-gray.
- Accent: slate blue-gray and green status text.
- Typography: clean sans-serif with restrained hierarchy.
- UI treatment: table rows, thin borders, minimal shadows.

## Page Structure

1. Top nav:
   - Simple brand text: `GigForge`.
   - Right-side outlined `Sign in` button.
   - Bottom border separating nav from content.

2. Hero:
   - Two-column desktop layout.
   - Left side: copy and CTAs.
   - Right side: structured data/table preview.

3. Kicker:
   - Uppercase tracking text:
     - `Built for student projects`

4. Headline:
   - Large but not flashy:
     - `A calmer way to find collaborators before the deadline.`

5. Supporting copy:
   - Explain that structured profiles and gig listings replace group-chat chaos with filters, portfolio links, and direct contact.

6. CTAs:
   - Primary dark button: `Browse gigs`
   - Secondary outlined button: `Create profile`

7. Ledger preview:
   - White bordered panel.
   - Header row with three columns:
     - `Field`
     - `Example`
     - `Status`
   - Rows:
     - Project / Short film score / Open
     - Needs / Cello, ambient synth / 3 matches
     - Deadline / April 18 / Direct email
   - Status values should use green text.

8. Feature row:
   - Three muted gray blocks beneath table:
     - `01 Filter people`
     - `02 Post briefs`
     - `03 Contact directly`

## Implementation Notes

- Avoid oversized decorative hero art.
- Prioritize scanability and alignment.
- Use borders more than shadows.
- The page should feel like the product is organized and reliable.
