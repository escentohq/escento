# Design Doc: Black Box

## Goal

Create a premium, minimalist dark landing page for GigForge. This design should feel serious and polished, like infrastructure for student creative work rather than a casual bulletin board.

## Visual Direction

- Style: stage-lit black box theater / premium dark product.
- Mood: focused, elegant, restrained, confident.
- Background: black.
- Primary text: white.
- Secondary text: neutral gray.
- Accent: acid green.
- UI treatment: black panels, thin dark borders, subtle radial glow.
- Typography: large clean sans-serif headline.

## Page Structure

1. Main layout:
   - Two-column desktop layout.
   - Left: hero copy and CTAs.
   - Right: dark process panel.
   - Mobile: stack.

2. Brand label:
   - Uppercase acid-green text:
     - `GigForge`

3. Headline:
   - Huge white headline:
     - `Put the right musician in the room.`

4. Supporting copy:
   - Explain that this is a premium, stage-lit direction for positioning GigForge as simple infrastructure for student creative work.

5. CTAs:
   - Primary white button with black text:
     - `Find musicians ->`
   - Secondary dark outlined button:
     - `Post a gig`

6. Right-side panel:
   - Black or near-black bordered rectangle.
   - A subtle acid-green blurred glow near the top center.
   - Three stacked rows at the bottom:
     - `* Open gig` with `01`
     - `* Matched profile` with `02`
     - `* Direct email` with `03`
   - Rows should use black translucent background and dark borders.

## Implementation Notes

- Keep the page extremely restrained; let spacing, contrast, and one accent color do the work.
- Avoid busy decoration or fake charts.
- This should feel premium but still explain the product.
