# Design Doc: Indie Magazine

## Goal

Create an editorial music-culture landing page for GigForge. This design should feel human, local, and arts-oriented while still making the core actions obvious.

## Visual Direction

- Style: independent magazine or arts review.
- Mood: thoughtful, cultural, student-scene aware.
- Background: very light warm white.
- Primary text: dark brown/black.
- Accent: muted red.
- Typography: serif display headline mixed with clean sans-serif body and labels.
- UI treatment: thin rules, section dividers, article-like feature blocks.

## Page Structure

1. Masthead:
   - Centered top text in italic serif:
     - `GigForge Review`
   - Bottom border under masthead.

2. Main layout:
   - Two-column desktop layout.
   - Left side: hero editorial story.
   - Right side: `Now listing` sidebar.
   - Mobile: stack hero then sidebar.

3. Kicker:
   - Uppercase red label:
     - `A directory for campus sound`

4. Headline:
   - Large serif:
     - `The next collaborator is probably three buildings away.`

5. Supporting copy:
   - Explain that the direction makes GigForge feel cultural, local, and human while keeping actions direct.

6. CTAs:
   - Primary dark button:
     - `Read the directory`
   - Secondary outlined button:
     - `Submit a gig`

7. Sidebar:
   - Left border.
   - Serif heading:
     - `Now listing`
   - Three article-like entries with top borders:
     - `Feature 01 / Short films seeking score`
     - `Feature 02 / Indie games needing texture`
     - `Feature 03 / Campus events booking live sets`
   - Each entry includes support copy:
     - `Browse anonymously, contact by email, keep the project moving.`

## Implementation Notes

- Do not make this look like a generic newspaper clone; it should be refined and artsy.
- Keep rules thin and spacing generous.
- Preserve strong CTAs despite the editorial mood.
