# MVP Style Guide

## Brand Feel
The app should feel:
- modern
- creative
- energetic
- student-friendly
- polished but not corporate

This is a platform for musicians and creators, so it should not feel sterile or ultra-enterprise.

## Visual Direction
- dark mode default
- deep charcoal / off-black background
- warm accent color: electric blue, violet, or amber
- soft gradients allowed, but subtle
- rounded cards
- gentle shadows
- modern sans-serif typography
- clean spacing
- colorful genre/instrument chips
- avoid pure black/white everywhere

## Design Rules
- no clutter
- no over-animation
- no “crypto dashboard” look
- no boring grayscale-only UI
- one strong accent color, one secondary accent max
- cards should feel lightweight and modern
- landing page should feel inviting, not corporate

## Component Style
- buttons: rounded, medium weight, clear hover states
- cards: slightly elevated, rounded-xl or 2xl
- badges/chips: soft filled backgrounds
- forms: clean inputs with visible focus states
- navbar: simple, elegant, slightly translucent if easy

## Pages
- landing page should have a subtle visual hook
- musician cards should feel vibrant and skimmable
- profile pages should feel like creative portfolios, not resumes
- gig cards should feel structured and opportunity-focused
